This course explains TeachMe using TeachMe. You will follow a `.teachme/` folder from disk
to the screen: how the loader turns folders and frontmatter into a table of contents, how
the local server exposes it, how the React app renders lessons and runs quizzes, and how
`teachme status` uses git history to tell which lessons went stale.

Each section ends with a short quiz, and a final quiz covers the whole course. Every lesson
lists the files it describes under **Sources**.
